March 02, 2026

Critical Fix

  • Zone Dimming Restored — Fixed a regression where Zone Level dimming stopped detecting and tracking bright regions entirely. The overlay activation flag was not being set when entering intelligent mode, causing all zone dimming overlays to be silently discarded.

Details

  • Root Cause — The v1.0.6 pause/decay fix added a safety guard to prevent overlays from appearing after dimming was paused. However, this guard also blocked overlays from being created during normal Zone Level operation because the activation state was never set for intelligent mode.
  • What Was Affected — Zone Level (per-region) dimming mode was completely non-functional. Full Screen and Window Level modes were unaffected.
