See SuperDimmer In Action

Seven powerful features working together. Intelligent dimming, workspace management, and eye comfort—all automated.

🎯 Per-Region Brightness Detection

Scans your screen as a grid (4×4 up to 16×16). Bright regions are detected and dimmed individually—dark areas stay untouched. Perfect for dark mode apps with bright content inside.

→

🌡️ Color Temperature Control

f.lux-style blue light filter built in. Shift from 6500K daylight to 1900K candlelight. Schedule automatically based on time or sunrise/sunset at your location.

🧭
✉️
Inactive apps hidden after 5 min

👻 Auto-Hide Inactive Apps

Apps you haven't touched for 5+ minutes? Hidden automatically (like pressing ⌘H). Keeps your workspace clean. Configure the delay or exclude specific apps.

Super Spaces HUD

Revolutionary floating HUD for managing macOS Spaces. Switch between desktops with keyboard shortcuts (Cmd+1-9), add notes to each Space, and see all your workspaces in a beautiful overview grid. Visual indicators show visit order and recent activity.

Progressive Dimming

Windows progressively dim based on when you last used them, creating a clear visual hierarchy. Current window bright, recently used slightly dimmed, inactive windows fade further. Your workspace naturally guides your attention.

Idle-Aware Timers

Smart timer pause when you step away. Auto-hide, auto-minimize, and progressive dimming all pause during inactivity. Return to find everything exactly as you left it—no unwanted changes while you're away.

Introducing Super Spaces HUD

Lightning-Fast Navigation

Press Cmd+1 through Cmd+9 to instantly jump between your Spaces. No more swiping or Mission Control delays.

Beautiful Overview Grid

See all your Spaces at a glance. Add notes to remember what you're working on. Never lose context when switching workspaces.

Every Feature You Need

SuperDimmer packs serious functionality into a lightweight menu bar app.

Per-Window Dimming

Different dim levels for active vs inactive windows. Focus on your current task while background windows fade away.

Sunrise/Sunset Scheduling

Uses your location to calculate sun times. Automatically shifts color temperature as the day progresses.

Excluded Apps List

Some apps shouldn't be dimmed (video players, color-critical work). Add them to the exclusion list with one click.

Multi-Display Support

Works across all your monitors. Each display is analyzed and dimmed independently.

Configurable Grid Precision

Choose detection grid from 4×4 (fast) to 16×16 (precise). Balance between accuracy and performance.

Launch at Login

Set it once, forget about it. SuperDimmer starts automatically when you log in and sits quietly in your menu bar.

Super Spaces HUD

Floating workspace manager with keyboard shortcuts (Cmd+1-9). Add notes to each Space, see visual overview, and switch instantly between desktops.

Progressive Window Dimming

Windows progressively dim based on usage order. Most recent windows bright, older windows fade. Creates natural visual hierarchy for better focus.

Idle Detection

All timers pause automatically when you step away. No unwanted auto-hide or dimming changes while you're idle. Everything stays exactly as you left it.

Per-Space Notes

Add persistent notes to each macOS Space. Remember what you're working on, track tasks, or leave yourself reminders. Notes sync across restarts.
